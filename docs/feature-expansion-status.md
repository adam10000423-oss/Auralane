# Feature Expansion Status

Status for Auralane 1.1.0. See the versioned release notes for the user-facing
change list and compatibility limitations.

## Integrated

- Playback and lyrics-search diagnostics, with redacted transport details.
- Queue snapshots, restore, delete/undo, bounded automatic backups and export.
- Account-scoped listening time with week, month and year daily summaries.
- Declarative HTTPS source configuration, secure headers, health and media checks.
- Manual YouTube song-version search and selection.
- Opt-in Last.fm, ListenBrainz and local Discord IPC adapters.
- Public Spotify playlist import, explicit matching review and cancellation.
- Opt-in local Listen Together host and read-only authenticated guest protocol.
- Public Listen Together relay and desktop create/join dialog, with credentials
  confined to the main process, reconnects and personal queue recovery.
- Low-power and reduced-motion controls; bounded optional tempo analysis.
- Measured-tempo crossfade suggestion, applied to the existing crossfade setting.
- User-supplied HTTPS video artwork with visibility/playback lifecycle controls.
- Rule-based smart playlists on the Playlists page with account-scoped IndexedDB persistence.
- Sidebar Replay with real song/artist daily listening aggregates, legacy daily totals and backup/restore.
- Real equal-power two-track crossfade and conservative, bounded worker-based beat-aligned Automix.
- On-demand snapshot/version dialogs, categorized settings and optional lightweight glass materials.
- Stop after the current song or the current queue, including shuffle order.
- LyricsPlus mirror racing and syllable/word timing preservation.
- KuGou KRC, Musixmatch RichSync and nested TTML parsing.
- Additional lyric-provider adapters with explicit identity-confidence handling.
- Manual lyrics choices cannot be replaced by a pending automatic search.

## Still Required Before Claiming Full Scope

- Official Spotify OAuth integration is not supplied; the implemented persistent
  web-session library flow remains subject to upstream compatibility.
- Complete source-module playback routing and verification against real media.
- End-to-end playback testing on separate physical computers and networks.
- Broader perceptual Automix validation across genres, phrase/vocal-aware planning and unsupported transport coverage.
- Automatic licensed dynamic-artwork discovery, rather than a manually supplied URL.
- Additional provider-specific credential flows and live availability verification.
- Queue/list virtualization and measured performance comparisons on large libraries.
- Ongoing third-party account compatibility testing across regions and providers.

Source adapters do not guarantee availability or lossless audio. Provider network
errors are not evidence that a song has no lyrics. Word timing is accepted only
from actual provider timing data, never generated by evenly spacing words.

## Verification

```sh
npm test
npm run test:features
node src/renderer/performanceTools.js
```

Live Electron checks use a separate `--auralane-preview` profile, not the signed-in
production profile. Pay That Toll by OneRepublic has been verified through actual
renderer IPC to return word-timed lyrics from LyricsPlus and KuGou. Availability
and latency are observations, not service guarantees.
